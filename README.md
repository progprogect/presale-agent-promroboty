# presale-agent-promroboty

Веб-приложение пресейла «Промышленные роботы»: интерактивные страницы для внутренней
проверки декомпозиций работ (WBS), в перспективе — интерактивные коммерческие предложения.

**Текущее состояние: v0.1-test** — демо-страница с вымышленными данными для проверки
развёртывания GitHub → Railway. Правки на странице не сохраняются.

## Развёртывание на Railway

Деплой из этого репозитория, ручные настройки не нужны:

- сборка: Python (по `requirements.txt`);
- запуск: `python main.py` (задан в `railway.json` и `Procfile`), порт берётся из `PORT`;
- проверка живости: `GET /health`.

## Локальный запуск

```bash
pip install -r requirements.txt
python main.py
# http://localhost:8000
```

## Структура

- `main.py` — сервер (FastAPI), отдаёт статику и `/health`;
- `static/index.html` — демо-страница декомпозиции работ (самодостаточный HTML);
- `railway.json`, `Procfile` — команда запуска для Railway;
- `requirements.txt` — зависимости.

Все данные на демо-странице вымышленные; реальные названия заказчиков в материалах
не используются.
